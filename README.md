Entry for the make.fun bounty
[One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68):
one original line, at most 200 characters, naming a hilariously useless
superpower. A deadpan comedy judge compares the lines two at a time and the
top three take the $5 pot.

## The entry line

> I can find anything I've lost, the moment I buy a replacement.

**Character count: 62** (limit: 1–200 characters).

## Files

- `main.ts` — writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (default `/output`), with no trailing newline.
- `README.md` — this file.
- `LICENSE` — MIT License.

## How it runs

```sh
node main.ts
```

The program creates the output directory if needed and writes the entry line
as UTF-8 text.
